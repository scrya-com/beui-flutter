# Compare a Flutter demo to the React original

1. Run the gallery: `cd apps/gallery && flutter run -d chrome`
2. Open the matching React page: `https://beui.dev/components/{category}/{slug}`
3. Exercise the same gestures: hover (desktop only), press, keyboard, reduced motion (OS setting), light/dark.
4. Check controlled state: if the parent holds `value`, the widget must not write it.
